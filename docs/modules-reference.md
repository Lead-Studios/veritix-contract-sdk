# SDK Modules Reference

## Overview

The VeriTix SDK provides focused domain modules for managing Soroban smart contract interactions:

- **AdminModule**: Two-step admin rotation, whitelist management, and fee configuration.
- **BatchModule**: High-throughput batch transfers, batch minting, and batch freezing.
- **EscrowModule**: Multi-party escrow lifecycle, automated release, and dispute resolution.
- **TokenModule**: Standard token operations, metadata updates, and allowance approvals.
